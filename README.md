# Anime Quote Guessr

Главная страница учебного проекта на Laravel 12 и Tailwind CSS. Приложение вдохновлено форматом "угадай аниме по изображению" и демонстрирует работу с анимированными элементами, счётчиком до ежедневной загадки, управлением подсказками и антиспойлером.

## Что реализовано

- Современная главная страница с адаптивной сеткой и градиентным фоном.
- Переключение светлой/тёмной темы с сохранением выбора в `localStorage`.
- Таймер до следующей дневной загадки, интерактивная панель подсказок и блок антиспойлера.
- Пример рейтинга игроков и карточки прогресса с анимациями.
- Настройка Tailwind CSS через Vite, пользовательские анимации и эффект парения элементов.

## Требования

- PHP 8.2+
- Composer 2+
- Node.js 18+ и npm 9+
- SQLite (опционально, если требуется постоянное хранение данных)

## Подготовка окружения

```bash
cp .env.example .env
php artisan key:generate
```

При необходимости обновите параметры подключения к базе данных в `.env`.

### Настройка базы данных (опционально)

Главная страница не зависит от базы данных. Если вы планируете подключать хранение результатов или другие фичи, включите SQLite:

```bash
touch database/database.sqlite
php artisan migrate
```

Убедитесь, что в `.env` указано `DB_CONNECTION=sqlite` или настройте любое другое подключение.

## Установка зависимостей

```bash
composer install
npm install
```

## Режим разработки

Для запуска локального сервера и Vite в режиме разработки используйте две команды (в отдельных терминалах):

```bash
php artisan serve
npm run dev
```

После запуска страница будет доступна по адресу `http://localhost:8000`.

## Сборка фронтенда

```bash
npm run build
```

Готовые ассеты появятся в каталоге `public/build` (директория исключена из Git).
